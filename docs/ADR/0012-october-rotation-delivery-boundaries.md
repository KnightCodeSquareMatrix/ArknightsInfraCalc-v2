### D3. 状态词的解释

- **完成**：该行限定的已提交行为有对应实现和历史验收；不把未验证的外部消费者或更强保证纳入“完成”。
- **部分完成**：其中明确的能力已进入提交，但用户请求的更大接受边界仍有实现、比较或证据缺口。
- **未实现**：裁决或设计已存在，但当前没有对应产品入口/实现。
- **工作区实现中**：代码或接口只存在于当前 dirty / untracked 工作区，除非后续提交并完成匹配验收，否则不计为交付。

## 关闭边界与后果

1. 仅 24/24 已按本 ADR 的完整已提交范围关闭；挂件开关只对 CLI / Worker 接口关闭，网站接线不作结论。
2. 四赤金专用准入、普通完整 Trade 候选比较是两个阶段；完成前者不能关闭后者。
3. 中枢基础轮休修复不等同于完整落实所有组合偏好；不得把“尽量单独”静默变成硬禁配。
4. 自动轮换作为独立建议模式由 `plan --rotation auto` 实现，验收和交付以其当前记录为准，不能借用 timed rotation 完成状态。
5. 泡泡 / 火神当前 WIP 不得计为 `cb73864` 的已提交交付，不得把 `CONTINUE` 或运行批次通过率写成独立复核 `PASS`。
6. 本 ADR 不关闭或替换 `docs/TODO/排班统一内核重构方案.md`、中枢顺序选位 active-change、泡泡 / 火神 ADR 实现阶段或其他 tracker；各领域 current owner 仍按上述文档和接口页维护。
