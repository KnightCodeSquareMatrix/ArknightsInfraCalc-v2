# 定时换班

> 文档角色：canonical
> 生命周期状态：current
> 代码范围：crates/infra-core/src/schedule/team_rotation.rs、crates/infra-cli/src/commands/plan*.rs
> 知识库桥接：docs/知识库引用.md（机制正文与版本由隔壁知识库裁决）
> 代码锚点：TimedRotationProfile、schedule_timed_rotation、TeamShiftResult
> 关联链路：docs/调用链/定时轮换.md、docs/菲亚梅塔使用规则.md
> 核验基线：六个 profile 与最终 invariant

定时换班服务 MAA 和人工固定时刻执行，输出完整班次表；不负责 Mower、游戏内置自动轮换或跨周期永续优化。

当前 profile 为 abc_12_6_6、abc_12_12_12、main_backup_12_12、fiammetta_witch_12_12、fiammetta_8_8_4_4、abyssal_7_5_7_5。裸 4、五班及以上和自由时长数组硬错误。当前 solver 是既定 facility policy 下的求解，不宣称全局最优。

生成顺序为：profile 分派 → owner/peak assignment → split 或专用状态 → Plan dependency/shift_bind → 中枢、办公室、会客室补位 → 菲亚/无人机/dorm_rest → 效率与宿舍 finalizer → invariant/warnings → CLI/MAA 输出。

显式二班、菲亚四班和深海四班执行 profile 专用连续工作/恢复校验并保留 0.5h 余量；默认 ABC 只产生 peak_mood_eta。机制心情公式引用知识库，本页只写 ETA、阈值和错误传播。

菲亚次数、时机、目标去重由菲亚梅塔使用规则唯一裁决；无人机由 schedule 选择实际赤金制造房；MAA 只投影动作。成功返回 TeamRotationReport，普通办公室/会客室/宿舍候选不足返回 warnings，profile 前提、容量、绑定、恢复和连续工作失败返回 error。
