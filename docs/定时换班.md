# 定时换班

> 文档角色：canonical
> 生命周期状态：current
> 领域键：schedule.timed
> 当前真源：self
> 摘要：定义固定时刻定时轮换的求解器行为和输出边界
> 代码范围：crates/infra-core/src/schedule/team_rotation.rs、crates/infra-cli/src/commands/plan*.rs
> 知识库桥接：docs/知识库引用.md（机制正文与版本由隔壁知识库裁决）
> 代码锚点：TimedRotationProfile、schedule_timed_rotation、TeamShiftResult
> 关联链路：docs/调用链/定时轮换.md、docs/菲亚梅塔使用规则.md
> 核验基线：七个 profile 与最终 invariant

定时换班服务 MAA 和人工固定时刻执行，输出完整班次表；不负责 Mower、游戏内置自动轮换或跨周期永续优化。

当前 profile 为 abc_12_6_6、abc_12_12_12、main_backup_12_12、main_backup_24_24、fiammetta_witch_12_12、fiammetta_8_8_4_4、abyssal_7_5_7_5。裸 4、五班及以上和自由时长数组硬错误。当前 solver 是既定 facility policy 下的求解，不宣称全局最优。

生成顺序为：profile 分派 → owner/peak assignment → split 或专用状态 → Plan dependency/shift_bind → 中枢、办公室、会客室补位 → 菲亚/无人机/dorm_rest → 效率与宿舍 finalizer → invariant/warnings → CLI/MAA 输出。

所有 profile 最终状态都按下节统一周期预算核验，专用 profile 原有连续工作/恢复和安全余量校验继续独立生效。`main_backup_24_24` 的每个状态是一个完整 24h 计划：生产搜索使用 24h 长班口径，带 12h 后心情衰减的制造成员不进入该长班；必选生产/功能成员无法覆盖 24h ETA 时返回错误，不把 24h 状态偷偷拆成两个 MAA 班次。ABC 保留 peak_mood_eta 作参考，中枢、办公室、会客室候选用班初心情及实际组合净消耗提前检查；已归入其他岗位的成员不得作为普通办公室补位，绑定办公室成员按其 Plan 角色落位。`12/12/12` 实际休班按回满近似，`12/6/6` 原有逐班准入不凭空计入宿舍恢复。可选中枢锚点使组合 ETA 不可行时，允许退回其可选角色并重编完整 Plan；required anchor 和已形成的 shift_bind 不在轮换中拆除。机制公式引用知识库，本页只写预算、近似和错误传播。

ABC 当前先尝试生产半区的默认朝向；明确的非生产岗位 ETA 失败后，完整重算另一朝向，让两块既有完整半区交换 α/β 的工作与休息位置。绑定闭包、required anchor 和 reserve 不拆分、不删除，γ 替补、辅助岗位与心情状态重新构建。两朝向均未找到时，才按已确认的可选中枢角色来源重编 Plan；其他错误原样传播。每朝向每次中枢选位仍最多尝试 64 个拒绝名单分支，属于有界近似，预算耗尽不能证明领域无解。两个 ABC profile 均须核查 S3 与下一 S1 同人在岗的预算，不能以 `12/12/12` 休班回满近似豁免首尾连续工作。

## 全模式周期心情预算

用户已裁决所有轮换方式、班次数和周期采用同一连续工作检查。检查对象是每班最终 `assignment` 的实际岗位、实际时长和实际中枢组合；最后一班与下一周期第一班相邻，周期结束、换房、换设施或换队伍标签都不恢复心情。中枢、制造、贸易、发电、会客、办公室的净消耗统一由现有 MoodModel 结算，按同一个干员跨设施累计。最终门禁须覆盖每个班次起点的环形连续工作段，并检查初始心情至首个恢复边界的前缀。

离岗一班作为既有连续工作预算的满休边界近似，不证明实际宿舍已入住或回满；ABC `12/6/6` 原有不预支宿舍恢复的更严格逐班准入继续有效。最终写入的菲亚 `pre` 动作在对应班次消费前重置目标预算，候选或预定动作不算恢复。整轮没有离岗或恢复动作且周期净消耗为正的成员必须拒绝；零净消耗仍可通过心情门禁，并按现有规则保留休班质量诊断。required、bind 或共享角色不豁免心情预算，也不能为通过而静默拆除。

所有耗心情活动必须显式覆盖或明确拒绝未知活动。训练教官是否工作及额外消耗需要训练任务上下文，当前班次没有该活动输入时不得宣称已验证，实际训练室或独立训练副手占用返回不支持活动错误。加工站按加工事件瞬时扣心情，现有定时班次没有加工事件；仅占位的加工站不计算小时消耗，也不能充当休息回满边界。若增加加工事件，须先接入活动成本 owner 后才能纳入保证。

该检查是 hard constraint，不是排序分数。所有候选在比较收益前均须通过；无菲亚候选被预算拒绝不等于独立的菲亚候选也不合法。没有合法候选时返回可定位到干员、班次和岗位的求解错误，不把部分排班作为正常 CLI/MAA 成功输出，也不声称已证明账号全局无解。

## 主备 24/24

用户确认的 `main_backup_24_24` 是主班 24h、备班 24h，总周期 48h。CLI 使用 `--rotation 24/24` 或 `main-backup-2424`，Worker v5 使用 `main_backup_24_24`。两个 owner 分别完整求解，备班从主 assignment 已占成员之外建池；两班各有自己的 Plan、中枢和生产房，所有实际工作人员按主/备归属上班。daily 用 48h 分母，表示 24h 平均产出。

中枢候选在 top-K 截断前按临时完整五人组合调用现有心情 owner；Plan 已满五人的路径也检查同一预算。该筛选是本 profile 的工作时长硬约束：实际净消耗乘 24h 不得超过班初心情预算。required 不拆、原有中枢排序不改；当前 Plan 或候选策略找不到可持续组合时保留求解错误，不宣称全局无解。固定版本知识库《心情与宿舍》“预设换班频次反推”将两班 24/24 与三组连续 48h 区分；运行时继续由现有 `MoodModel` 与实际 assignment 计算，不新增心情公式。

普通宿舍仍由相邻班次实际工作差集生成，已有住员优先保留；床位不足产生 warning 并投影 MAA autofill。`DormRestPlan` 专用于固定恢复组，菲亚动作班回宿舍的事实写在最终 assignment，不要求该字段非空。24h 离岗和 autofill 不能证明全部休班成员实际已获得恢复；本模式不声明跨周期宿舍永续保证。菲亚每个状态边界最多一次，24h 内部不增加隐式换班或多动作。MAA 输出两个计划并说明下一计划间隔 24h，触发由执行侧配置。

Rust 最终状态门禁的 `main_backup_24_24_topology`、`plan_anchor`、`work_disjoint`、`bind`、`capacity`、`work_budget` 与 `manufacture_work` 核对实际两班、owning Plan 和工作成员；周期权重、菲亚动作/目标/宿舍及休班诊断继续由统一门禁核对。该 profile 也必须通过全模式周期预算；训练室/训练副手缺活动输入明确拒绝，加工站只有占位时按上节边界处理，不声明加工事件或训练任务心情保证。

## 每周期休班底线（目标规则）

任意一个完整定时轮换周期内，实际在工作岗位出勤的每名干员，至少有一班不在工作岗位工作；二班、三班及四班 profile 均按各自完整周期判断。工作状态取每班最终 `assignment` 的实际岗位与状态，涵盖中枢、贸易、制造、发电、会客室、办公室、加工站、训练室普通成员及独立的 `training_assist` 训练副手。宿舍成员不计工作。离岗或进入宿舍可以是不工作，但未在岗不等于已经获得宿舍恢复。队伍标签、候选名单、`shift_bind`、required、pinned 或被称为“挂件”均不能替代实际出勤判断，也不自动获得豁免。

仅有两项具名豁免：实际被选入自动化组合的 Lancet-2，可按该体系的 0 心情发电与加工站去向安排；以及本周期某一班最终确实写入菲亚梅塔心情交换动作的 `target`。只列为菲亚候选、预定目标或体系所需成员不算实际动作目标；其他自动化成员、普通支持位和莱茵挂件没有豁免。详见[自动化组体系](公孙长乐的体系分析文档/AUTOMATION_GROUP_CHAIN.md)和[菲亚梅塔使用规则](菲亚梅塔使用规则.md)。

约束必须对所有 profile 的完整班次最终状态统一核对，包括 Plan 硬锚、shared 成员、后续补位与特殊动作；发现不休班时应能指出干员、各班工作房间及豁免判定，不能靠局部候选过滤或静默改排掩盖。本条休班诊断本身不使求解失败；独立的周期心情预算不满足时仍须拒绝结果，不能用 warning 豁免正消耗无恢复。

当前实现由 `finalize_timed_rotation` 在全部班次与宿舍最终落位后统一生成 `rotation_cycle_rest:` 质量诊断，写入 `TeamRotationReport.warnings`。诊断按干员名排序，逐班列出实际工作房间/岗位及无豁免判定。Lancet-2 豁免在每个实际工作班次核对 `plan_index` 对应的自动化入选成员、发电锚点及实际发电/加工站岗位，并要求周期中至少一班在对应发电岗位；其他 owner 的普通 Lancet-2 岗位不能借用该豁免，不凭拥有量、其他分支或仅有 0 心情判定。`--assert-invariants` 的 `rotation_cycle_rest_diagnostics` 从终态重算并核对诊断：漏报、误报、重复或陈旧诊断才是断言失败；整周期工作本身允许带诊断成功返回。这证明诊断与终态一致，不表示排班已经为每个人安排休班或自动修复违规。本条诊断口径不替代现有容量、绑定、恢复和连续工作校验各自的错误传播。

菲亚次数、时机、目标去重由菲亚梅塔使用规则唯一裁决；无人机由 schedule 选择实际赤金制造房；MAA 只投影动作。成功返回 TeamRotationReport，普通办公室/会客室/宿舍候选不足及每周期休班违规返回 warnings，profile 前提、容量、绑定、恢复和连续工作失败返回 error。
