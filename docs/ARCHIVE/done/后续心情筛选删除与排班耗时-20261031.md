## 2. 行为修改

| 修改 | 影响与责任 |
|---|---|
| 删除 `layout/work_budget.rs`、`schedule/room_admission.rs` 及预算字段传递 | 制造、贸易、发电、中枢组合不再反复重建工时预算；为此复制 owned 成员的路径一起删除 |
| 删除动态 required、固定 pin、办公室、会客室、回收站和普通补位的 ETA 复筛 | 已形成 Plan 和候选名单不会因后续工作心情被移出；普通空座继续消费原技能、占用、Team/Shift 与容量政策 |
| 删除所有模式制造 `>=12h` 负心情差身份排除及连续制造 validator | 原本被时长身份政策排除的候选参与真实窗口效率积分；保留暖机、心情差、分桶和上限的数值语义 |
| 删除菲亚目标完整周期工时淘汰 | 动作仍验证本人 ready、目标岗位、连续在岗与绑定；不以目标工作预算否定候选 |
| 删除深海 7/5/7/5 宿管恢复量与工作量比较的组合淘汰 | 宿管按真实恢复量排序，床位、身份与占用继续生效；恢复不足只作终态质量诊断 |
| 自动与定时终态心情问题保留 warning | 普通输出继续返回真实完整名单、班次与收益；显式 gate 重算并核对心情提示准确性，结构问题仍独立失败 |

终态只读检查保留真实净消耗计算。它不改名单、不缩班时、不重建中枢、不翻半区、不撤预算重试。菲亚物理 ready 与恢复来源互斥是机制条件，不属于已删除的工作预算筛选。

## 5. 剩余耗时

取 b-101-424 新版本第一份生产 `[perf]`，计时槽为 inclusive，父子阶段不可相加：

| 项目 | 自动，trace 2.158s | 三班，trace 2.963s |
|---|---:|---:|
| 制造尝试组合 / live calls | 2,259,874 / 27 | 1,752,816 / 34 |
| 制造实时评估 | 1261ms | 972ms |
| 制造排序与 top-K 物化 | 418ms | 318ms |
| 贸易尝试组合 / 实际 solver 调用 | 140,302 / 131,877 | 14,648 / 12,094 |
| 贸易评估 | 348ms | 58ms |
| 普通 resolve | 12ms / 91次 | 206ms / 1545次 |

自动初始 Plan 比较约 1406ms，其中制造约 1334ms；后续 pipeline 约 708ms。主要成本是正常选型的制造试排和求值，普通 resolve 已不是自动模式的大头。

三班 N/A/B 比较共三套候选构造；S2 约 1157ms，其中深海替班约 1100ms。`build_abyssal_s2_candidates` 枚举深海人数在可变制造房间的分布，各分布完成带 anchor 制造房，再组装中枢与真实效率结算；这解释了大量重复结构准备与 resolve。gamma 两半区约 592ms。最终结算总计约 10ms，JSON 写出约 1ms，不是主要成本。该归因定位阶段，不证明这些重复都能等价删除。

临时采样探针按确定性哈希采样约 1/256 组合，自动 10,082 个、三班 8,321 个样本；两份完整 rotation 与正式 binary 仅去顶层 elapsed 后相同。制造评估互斥外层采样中，数值 solver 约 89.8%/89.4%，成员借用约 4.2%/4.5%，工作窗口约 2.8%/2.6%，组合布局约 3.2%/3.6%。solver 内部静态 phases 约 18.8%/19.5%，心情差积分约 19.5%/16.5%，暖机积分约 7.9%/12.0%；其余包括时间效果识别、原子准备和未单独计时的求值工作。嵌套 `solve_at_gaps` 不与外层积分相加。

探针是已有临时源码产物，早于最后深海恢复阈值及无用参数清理；本次自动/三班产物已对齐。探针记录所有实际搜索，包括生产 perf 暂停记账的重放，三班原始组合总数与 trace 计数边界不同；不混用两种分母。样本计时用于定位，速度结论来自无细粒度探针的生产 binary。

## 6. Bake 与下一步设计边界

本次旧新速度对照均无有效 Bake 命中。自动制造入口在 `layout.auto_rotation` 时直接绕过 Bake；普通三班在 Layout/predicate 兼容门禁阶段回 live，不能称“Bake已加速”。此前有效 schema17完整表查询也证实自动与该三班样本 Bake 命中为零；有效表存在、冷校验通过与热入口实际命中是不同事实。

后续设计应优先回答：制造全量排序能否保持现有同分顺序和完整 Top-K；静态数值求值是否有可证明的共享部分；三班深海分布间能否复用相同输入的结构与结算；动态窗口/布局为何不满足 Bake 合同。此次只提供成本证据，不实施新缓存、Bake扩展、候选剪枝或减少 N/A/B。已删除的动态全响应缓存与心情重试不恢复。
