# 文档维护轻量化重构

> 文档角色：archive
> 生命周期状态：completed
> 替代项：docs/文档生命周期.md；docs/指南/CURRENT_STATUS.md；docs/TODO/README.md
> 历史原因：完成案件卡、当前实现路由、ADR 保留清理和引用检查收敛
> 摘要：记录文档维护轻量化迁移的完成范围与未决边界

## 1. 完成范围

- 建立 `docs/指南/CURRENT_STATUS.md`，集中提供高频维护域的当前实现入口。
- 将发电效率、严重排班问题等高频事项压缩为案件卡，保留现象、冻结输入、owner、首次违规层、保证等级、证据缺口和非目标。
- 清理超过半个月的 ADR 0001-0006，保留近期 ADR 0007-0009；同步闭合导航和检查器引用。
- 将文档内源码和数据行号链接统一为 `#L...` fragment，使仓库事实检查器能够验证目标文件存在。
- 保持 canonical、current-reference、active-change、decision 和 archive 的唯一责任边界，不新增第二套状态机或全仓影响清单。

## 2. 当前承接关系

| 内容 | 当前 owner |
|---|---|
| 文档角色、状态、关闭和归档 | `docs/文档生命周期.md` |
| 高频实现路由 | `docs/指南/CURRENT_STATUS.md` |
| 活动任务索引 | `docs/TODO/README.md` |
| 领域规范和当前实现 | 对应 canonical / current-reference |
| 历史方案与审计材料 | `docs/ARCHIVE/` |

## 3. 未决边界

活动任务仍由各自 active-change 负责，不因本次迁移自动关闭。长篇历史材料保留其审计价值；后续只有在事实已吸收、开放项已拆分且引用已闭合时，才按生命周期规则继续压缩或归档。
