## 不能直接当作缺陷的报警

| 报告项 | 判断依据 |
|---|---|
| 配方不匹配（5-9） | 赤金站确可使某个经验或源石配方 atom 不生效，但刻俄柏、远牙、稀音、褐果、野鬃还有其他通用技能/收益；“该干员技能空转”以整人为单位不成立。需核对实际 tier 的 buff 列表及各 atom 结算。 |
| 组合缺员、错班、分房（53-77） | 登记在审查器的组合不等于求解器实际选择该体系。赤金工艺和莱茵等有合法的单人或降级形态；只能对实际选中且要求同站/同班的规则检查 required placement，不能从名单不齐直接断言违规。 |
| Lancet-2 挂件（49） | 报告示例为 153、243 三电站布局，却套用了二电站森蚺联动前提；对这批样例的“必须与森蚺同班”报警不成立。参见 [自动化组体系](../公孙长乐的体系分析文档/AUTOMATION_GROUP_CHAIN.md)。 |
| 散件形态、忍冬搭档、会客替换（81-85、88） | 这些是可比较的候选改进，不是准入约束。忍冬与铃兰未同站会失去条件增益，但替换收益须计入替代成员的班次占用、休息与整个周期目标；局部百分比差不等于可实现净收益。 |
| 中枢光环重叠（86-87） | 冻结样例中的火龙S黑角为低档位，不能直接认定与诗怀雅/阿米娅拥有相同效果 atom；须读取该 box 的实际 tier 和 `EffectKey`。代码的 ledger 可对同 key 取最高，但其他非 ledger 资源不在这个结论中。 |
