## 2. 原则

1. **规则分层由 agent 判断。** AGENTS.md 分三层：硬约束、默认工作方式、先问再做。默认工作方式可以按任务裁剪，偏离时写一行说明。
2. **硬约束也会过时。** 每条硬约束写明来源（事故提交或用户裁决）。agent 发现某条已经不适用时，提出降级或删除的建议并附理由，由用户确认；用户确认前不自行绕过。
3. **只在明显划算时加检查。** 一项检查长期失败，要么修好，要么删掉，不留着。
4. **不造第二真源。** 规则只写在它的 owner 里，其他地方只放链接。
