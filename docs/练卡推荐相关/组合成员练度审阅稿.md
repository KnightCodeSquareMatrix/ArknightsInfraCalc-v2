## 读法

| 列 | 含义 |
|---|---|
| 层级 | 核心 / 重要 / 次级 / 挂件 |
| 目标 | 玩家侧培养/完成度目标；**无** = 无练度要求（拥有即可计持有） |
| 备注 | 启动条件、去重、双身份等 |

图例：`E2` 精二 · `E1` 精一 · `E0` 精零 · `无` 无练度门槛。
