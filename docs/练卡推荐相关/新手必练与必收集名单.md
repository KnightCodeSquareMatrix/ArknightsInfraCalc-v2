# 新手基建必练与必收集名单

> 文档角色：canonical
> 生命周期状态：current
> 领域键：advice.training.newbie
> 当前真源：self
> 摘要：定义直接练卡推荐第一层的新手必练、必收集干员、最低目标练度和特殊获取方式

## 1. 使用方式

本文名单是直接练卡推荐的第一层规则，不要求先运行排班求解器。

系统按干员逐项比对玩家干员盒：

| 玩家状态 | 输出处理 |
|---|---|
| 未拥有 | 显示为“必收集” |
| 已拥有，但低于本文目标练度 | 显示为“必练”并给出目标练度 |
| 已拥有，且达到或超过目标练度 | 视为完成，不再显示为待办 |
| 目标为精零且已拥有 | 视为完成，不产生练卡任务 |
| 目标为具体等级且尚未达到 | 显示为“必练”并给出目标等级 |

基础必练章节满足以下任一条件时可以整体跳过：

- 本文全部目标已经完成；
- 请求来自排班求解结果，且贸易人均效率 **> 30%**、制造人均效率 **> 25%**（T9；详见《玩家输出口径》）。

跳过本章节不删除干员的组合身份。若清流等干员仍是当前可完成组合的核心或重要成员，可以按组合理由继续推荐。

当本文未完成目标**多于 10 个**时，玩家报告仍最多展示 10 名干员：优先但书、可露希尔、巫恋、龙舌兰、清流、断罪者，再按赤金/经验 → 贸易 → 通用制造填充剩余名额。完整截断规则以《玩家输出口径》§5.1 为准；本文只提供名单与最低目标，不另定 cap。

知识库允许同一干员保留多个身份，玩家报告只生成一条练卡或收集建议：

- 若组合可启动，主要推荐理由按“组合核心 ＞ 组合重要角色 ＞ 高效率散件/组合次级角色 ＞ 挂件”选择；
- 若组合因其他核心缺失而无法启动，但该干员仍可独立作为高效率散件使用，可以改以高效率散件为主要理由；
- 不在主要理由后重复补充较低优先级身份；
- 不得为同一干员生成两条重复待办。

相同目标练度直接去重：**清流**和**断罪者**已经属于本文名单，后续高效率散件报告不得再次重复推荐相同目标。

不同目标练度分别判断：例如**苍苔**的新手必收集目标为精零，高效率赤金散件目标为精二。已拥有精零苍苔时，新手目标已经完成，但仍可以按高效率散件规则生成一条精二建议。

## 6. 后续引用约束

- 练卡推荐报告必须先完成本文比对，再处理组合完成度和高效率散件。
- 已完成项目不进入待办，但可计入账号总结中的完成情况。
- 未拥有的精零干员仍属于“必收集”；已拥有时不要求额外练度。
- 未拥有且存在特殊获取方式时，报告必须显示本文记录的获取入口；已拥有时不重复显示。
- 本文只记录最低目标练度，不自动把角色提高到更高精英阶段。
- 组合角色分级、组合完成状态和高效率散件名单在同目录其他文档中另行定义。
