## 2. 功能目标

将 Rust 已确定的 `PlayerTrainingAdviceReport v2` 整理成面向玩家的简体中文自然语言报告：

```text
结构化练卡事实
→ NarrativeInput
→ LLM 或确定性 fallback
→ JSON 校验
→ placeholder/canonical 替换
→ NarrativeOutput
```

LLM 只组织语言，不能计算、排序、推断、补充或改写业务事实。

## 3. 已实现范围

### 3.1 Python narrator 包

目录：[arknights_narrator](/home/knightcode/Projects/ArknightsInfraCalc-v2-remote-61.184.13.127/arknights_narrator)

- `projection.py`
  - 接收 `PlayerTrainingAdviceReport v2` 字典；
  - 校验 schema version；
  - 校验组合 id/name 与 mapping 一致；
  - 已成型组合最多 6 组；
  - 未完成且非 `needs_review` 组合最多 6 组；
  - 按完成率降序，原数组顺序作为稳定 tie-break；
  - 直接使用 Rust 传入的 `completion_percent`，不重新计算；
  - 只为已选中的组合摘要和推荐关联组合构造组合、干员和事实 placeholder 白名单。

- `adapter.py`
  - 读取环境变量；
  - 调用 OpenAI-compatible client；
  - 校验固定六章节 JSON；
  - 校验 canonical 标题、placeholder、字符数和建议数量，并拒绝未知顶层字段；
  - 拒绝自由填写精几、百分比、设施、干员名和组合名；
  - 支持一次可恢复错误重试和一次 JSON 修复请求；
  - 未配置 LLM 或调用失败时返回 fallback。

- `fallback.py`
  - 不依赖 LLM 的确定性中文报告；
  - 使用后端提供的组合、完成率、目标练度和设施事实；
  - 返回与 LLM 路径相同、只含 `schema_version` 与 `sections` 的 Narrative v1 内容。

- `mapping.py`
  - 外置 mapping 加载；
  - mapping version/hash；
  - 别名冲突校验与只读快照；
  - reload 失败保留上一份有效快照；
  - 仅支持 `zh-CN`。

- `cache.py`
  - 服务端内容 HMAC；
  - Redis key 命名空间；
  - `ready` 优先查找；
  - `SET NX` 锁接纳；
  - Redis 不可用时 fallback；
  - accepted 任务返回 fencing token，供 BFF Lua 发布、续租和安全释放锁；
  - fencing token 相关 Lua 脚本常量。

## 5. 本地验收前置条件

当前环境检查结果：

- 当前 Python：`3.12.3`
- 项目最低 Python：`>=3.12`
- 生产建议 Python：`3.12` 或 `3.13`
- 当前环境未安装 `openai`

因此，纯逻辑测试可以运行；真实 LLM 调用前需要在 Python 3.12/3.13 环境安装项目依赖。

安装依赖后配置：

```bash
export TRAINING_ADVICE_LLM_PROVIDER=openai
export TRAINING_ADVICE_LLM_BASE_URL=https://api.openai.com/v1
export TRAINING_ADVICE_LLM_MODEL=<model>
export TRAINING_ADVICE_LLM_API_KEY=<secret>
```

API key 不得写入仓库、fixture、日志或 shell 脚本。

本地直接测试，不需要 BFF、HTTP 或 Redis：

```bash
python3 scripts/smoke_training_advice_narrator.py \
  --report data/fixtures/training_advice_narrator_smoke_report.json \
  --env-file .env \
  --output /tmp/training-advice-narrative.json
```

退出码：`0` 表示 LLM 返回并通过事实校验的 `ready`；`1` 表示已生成确定性 `fallback`；`2` 表示调用前的输入、mapping 或 JSON 错误。`.env` 已被 `.gitignore` 忽略，但仍不得提交或复制 API key 到其他文件。

mapping 更新必须显式递增版本并使用生成工具的原子替换路径：

```bash
python3 scripts/build_narrator_mapping.py --version 1.0.1
```

## 8. 建议的真实 LLM 验收场景

至少覆盖：

- 正常返回符合 schema 的 JSON；
- 返回自由填写精二、百分比或设施名；
- 返回未知组合 id 或未知干员 id；
- 返回错误组合顺序；
- 返回非法 JSON；
- provider 超时、429、502/503/504；
- API key/model 缺失；
- mapping reload 后版本变化；
- 100 个相同内容请求；
- Redis Connection Refused/Timeout。

验收标准是：任何 LLM 或 Redis 异常都不能改变、阻塞或破坏 `plan.compute` 的结构化结果。
