> 核验基线：`947f1a2`

制造接收实际房间和配方，输出 `ManuResult`；没有贸易站的 gold flow、订单机制或 shortcut。L1 阶段解释配方效率、仓库上限、配方条件、tagged/global inject、PeerAbsorb 和心情；L2 由 solver 处理产线、storage 与班次 gap。

```text
ManuRoomInput
 -> ManuContext::from_room
 -> apply_manu_phases
 -> solve_manufacture[_with_shift]
 -> per-line result + storage + mood
```

`search_manufacture_triples` 先按 `full_pool` 过滤，单配方做三人组合；`Lines` 分别搜索金和作战记录，再由 `evaluate_manufacture_lines` 按线数聚合。排班的 `manufacture_fill` 还要满足 Plan anchor、`used`、容量和最新 LayoutContext。

非法配方/人数/等级返回错误；无解不偷换配方。心情 gap 由 rotation policy 处理。跨设施资源异常回 `resolve_base` 和 global chain。

核验：制造搜索报告、`layout eval --explain-json`、`plan --assert-invariants`、代表性 fixture。机制数字回知识库引用。
